# Web Architect Guidelines

## 1. Stack Selection
- Use modern HTML5, semantic tags, and responsive CSS (Flexbox/Grid).
- For frameworks, prioritize component modularity and clean state management.

## 2. Structural Planning
- Before writing code, list all required files, assets, and directory structures.
- Ensure a logical separation of concerns (HTML/JSX, CSS/Styling, JS/Logic).

## 3. UI/UX Excellence
- Implement a mobile-first responsive layout matching professional design standards.
- Use a cohesive color palette, modern typography, accessible contrast, and smooth transitions.

## 4. Code Quality
- Write self-documenting code with meaningful variable and function names.
- Never use placeholder comments or leave functions incomplete.
- Deliver fully production-ready, functional code in every file update.
